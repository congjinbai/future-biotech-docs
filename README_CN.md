# FUTURE BIOTECH V4

这个版本的原则是：**原文件内部不重新设计，只把原源代码作为文件引擎放进统一账户系统。**

公开 GitHub 仓库只需要上传：
- index.html
- viewer.html
- styles.css
- app.js
- config.js

不要把员工原始收条源代码直接上传到 GitHub。管理员登录后，在“模板”页选择本地原始 `.txt/.html` 文件并导入；文件内容会保存到 Supabase。

当前 TEST001 已临时设为管理员，用于测试。

## 重要
原始文件的排版、逐题输入、必填校验、签字板、手机适配、PDF/PNG/分享/打印逻辑均由原源代码执行。
V4 外层只负责：登录、权限、模板、发放/收回、复制、删除。
