# FUTURE HEALTH V31

本版本重点优化普通用户填写体验：

- 日期输入框改为一体式设计，右侧内嵌标准日历图标。
- 点击输入框仅使用数字键盘；点击日历图标才打开自定义月历，两种方式互不干扰。
- 日期支持 6 位输入，例如 `021026`，显示为 `02.10.26`，正式文件仍使用完整年份。
- 预览区增加“预览页 / Предпросмотр”、说明文字和展开/收起。
- 各填写阶段增加简短、当前步骤相关的提示语。
- 确认页按钮改为“确认并签字 / Подтвердить и подписать”。
- 签字后点击“确认签名”会自动生成最终文件，不再要求普通用户理解“生成图片”。
- 最终文件页增加提交前检查提示和“提交后发送给管理员”的说明。
- 统一以 `fh_lang` 作为系统主语言状态，同时兼容旧语言键，减少中俄文串台。
- 加入 FUTURE HEALTH Apple Home Screen 图标和 Web App manifest。
- 旧 receipt_v1 模板/文件在管理员加载后会自动升级到 V31 源界面。

## V32 更新
- 正式接入 iPhone Safari“添加到主屏幕”图标：`apple-touch-icon.png`。
- 增加 Web App manifest、favicon 与 iOS Web App 元信息，并加入 `v=32` 缓存版本。
- 使用已确认的 FUTURE HEALTH 公司图标重新生成 180×180 与 512×512 图标。
- 调整签字后的最终预览提示：确认无误即可提交；如需修改可返回重新填写。
- iPhone 上测试新图标时，请先删除主屏幕旧图标，再从 Safari 重新“添加到主屏幕”。
