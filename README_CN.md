# FUTURE HEALTH V16

本版修复两个问题：

1. 注册审核等待页
- 新用户提交注册后不再退出 Supabase 登录会话。
- “正在审核”页面每 2 秒检查一次审核状态。
- 管理员批准后，等待页立即尝试播放提示音、显示系统通知，并自动进入系统。
- 保留“更新”按钮作为手机桌面网页版的手动备用方案。

2. 管理员回执文件夹
- “查看”改为系统内预览，不再依赖浏览器弹窗。
- “下载”修复：桌面浏览器直接下载；iPhone/手机桌面网页版优先打开系统分享面板，可选择“存储到文件/保存图像”。
- “转发”使用手机系统分享菜单，可选择微信等应用。
- 查看/下载/转发后回执会标记为已读，红色未读数字同步更新。

建议本次完整覆盖 GitHub 仓库中的：index.html、app.js、styles.css、config.js、viewer.html、receipt-template.html、future-health-logo.png。
