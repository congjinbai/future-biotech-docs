# FUTURE HEALTH V10

本版本重点增加“可视化可编辑模板”。

- 注册时分别填写俄文姓名和中文姓名。
- 对于可编辑收条模板，姓名不再写死在 HTML 中，而是在打开文件时自动读取接收用户的账户姓名。
- 管理员可在“模板”页面直接编辑金额、护照信息、正文段落和填写问题。
- 新建文件时，也可以在发放前对当前文件内容做一次独立修改，不影响模板本身。
- 已将 3 个收条类原始模板自动转换为可编辑模板结构；申请书模板继续保留原 HTML 方式。
- 正文中支持 {q1}、{q2}……占位符，对应使用者回答的问题。
- 新增问题可选择日期、文字、电话或数字类型。

部署 GitHub Pages 时请一并上传 receipt-template.html。
