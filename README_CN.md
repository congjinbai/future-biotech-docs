# FUTURE HEALTH V11

本版主要更新：

- 注册页面按当前界面语言只填写一种姓名：俄文界面仅填俄文姓名；中文界面仅填中文姓名。
- 俄文姓名校验为“姓 名”或“姓 名 父称”。
- 管理员可在账户管理中补齐另一种语言姓名。
- 修复旧账号删除后手机号仍被注册申请占用的问题；以后删除账户会同时清理相关注册记录、手机号映射和文件请求。
- 模板支持重命名。
- 模板支持下载为 TXT；该 TXT 可再次作为 FUTURE HEALTH 模板包导入，包含名称、可视化配置和原始源代码。
- 复制模板后可直接重命名并继续编辑，保存为新的独立模板。
- 文件查看/填写页面改为外层 viewer 容器，返回按钮固定属于系统外层，不依赖模板内部代码；因此新旧模板打开后底部都应有返回按钮。

部署时覆盖：index.html、app.js、styles.css、viewer.html、receipt-template.html、future-health-logo.png。config.js 无需修改。
