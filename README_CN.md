# FUTURE HEALTH V13

本版在 V12 基础上新增“注册审核后自动进入系统”。

- 用户提交注册申请后，只要不关闭当前页面，系统每 4 秒检查一次管理员审核结果。
- 管理员点击同意后，等待中的用户会收到两声免费网页提示音。
- 页面显示“注册已通过，正在进入系统……”/“Регистрация подтверждена. Вход в систему…”后自动刷新并进入系统。
- 若浏览器已允许通知，也会同时弹出系统通知。
- 不需要短信服务，不产生短信费用。
- 若手机把网页彻底关闭或暂停后台网页，则无法保证实时响铃；重新打开页面后仍可正常登录。

本次主要覆盖 index.html 即可。viewer.html 和 receipt-template.html 继续沿用 V12 修复。
