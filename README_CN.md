# FUTURE HEALTH V30

本版重点重做普通用户填写文件的体验：

- 取消“开始 / 结束”两个可点击进度按钮，改为“第 1 / 2 步”式引导。
- 第二步保留“修改上一项”，填写完成后增加确认区，每一项都可单独修改。
- 日期支持 6 位数字快速输入，例如 `021026`，自动显示为 `02.10.26`。
- 日期输入框支持自定义月历：可切换月份、直接点日期，并有“今天 / 本月1号 / 本月最后一天”快捷按钮。
- 预览区增加“预览页 / Предпросмотр”。
- `{q1}`、`{q2}` 未填写时在预览中自动显示下划线占位；填入日期后占位线自动消失。
- “更新 / Обновить”改为“重新填写 / Заполнить заново”。
- 提交成功、返回主页等系统按钮跟随当前文件语言，降低中俄文串台风险。
- 返回主页按钮降为白底描边的次要操作。
- 编辑正文支持 `<b>文字</b>` / `<b>текст</b>` 加粗固定文字。
- 对旧的可视化收条模板/文件，V30 会优先使用最新填写界面，并在管理员加载后台时自动升级其 source_html。
