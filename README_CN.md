# FUTURE HEALTH 文件系统 V5

本版本在 V4 基础上增加：
- 使用者登录后可自行修改密码；
- 管理员可把任何账户密码恢复为统一初始密码 `12345678`；
- 新账户默认密码固定为 `12345678`；
- 管理员可修改包括自己在内的账户显示名称；
- 模板可新增、替换、删除；
- 管理员查看文件时为只读模式，并提供返回按钮；
- 普通使用者打开文件后始终有“返回我的文件”按钮，页面底部也有“退出文件，返回文件列表”；
- 系统名称改为 FUTURE HEALTH，并加入公司 Logo。

说明：忘记密码邮件自动发送功能本版暂未启用，因为现有登录体系使用“个人编号 + 内部登录邮箱映射”。目前采用管理员一键恢复为 `12345678` 的方案。
