# FUTURE HEALTH V22

本版本在 V21 基础上继续调整：

- 用户签字提交成功后，先弹出“已成功提交，返回主页 / Документ успешно отправлен”确认框，确认后再返回主页。
- 签字页最终按钮统一为“提交 / Отправить”。
- 文件填写页左上角“更新”现在等同于“重新填写”：清空当前回答和签字并回到文件初始状态。
- 日期题继续支持数字键盘输入，同时增加可见的日历弹窗；点击日历图标或长按日期输入框均可打开。
- 管理员文件页新增批量删除模式：全选、取消、删除所选。
- 管理员模板页新增同样的批量删除模式。
- 账户管理新增权限设置：普通用户 / 二级管理员 / 管理员。
- 二级管理员权限：不显示模板；文件仅可查看、编辑内容、发放/收回；账户可新建普通账户、修改普通用户姓名、恢复普通用户初始密码；回执仅查看。禁止文件下载/重命名/复制/删除，禁止账户删除和角色设置，禁止回执下载/删除。
- 二级管理员权限同时由 Supabase 后端策略约束，不只是隐藏按钮。

建议整包覆盖 GitHub 现有文件。

## 二级管理员说明
管理员可在“账户管理 → 权限设置”中把普通用户设为“二级管理员”。当前登录的主管理员不能把自己的角色降级，避免误锁定后台。
