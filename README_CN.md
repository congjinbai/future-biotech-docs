# FUTURE HEALTH V21

本版本在 V20 基础上调整以下功能：

- 注册姓名输入限制：俄文界面只允许俄文字母和空格，并自动大写；中文界面只允许汉字、英文字母和空格，英文字母自动大写。
- 俄文姓名输入允许正常输入空格，用于分隔姓、名和父称。
- 登录个人编号和密码恢复为普通字母数字键盘；登录编号仍提示手机号，但兼容英文字母+数字的个人编号。
- “新建文件”可从“🧩 模板”或“📄 已有文件”中选择；已有文件可直接发放给指定用户。
- 管理员文件列表增加“下载”按钮，下载 TXT 文件包。
- 日期题继续使用数字键盘，同时增加日历按钮；长按日期输入框也会尝试打开系统日历。
- 填写文件时删除“打印文件”及其打印说明，只保留“在线签字”。
- 签字生成图片后删除“打印纸质文件”，只保留“提交并返回 / Отправить”。提交成功后自动回到用户主页面。
- viewer 对旧模板也会隐藏旧的打印按钮和打印说明，因此不需要逐个重新制作旧文件。
