# FUTURE HEALTH V20

本版本重点修复 V19 的回归问题：

- 修复“正在审核”页面脚本语法错误；管理员发送修改提示后，用户可在当前审核页面收到提示并修改后重新提交。
- 恢复管理员审核通过后的即时提示音、通知文字和自动进入系统。
- 修复管理员恢复初始密码时 Edge Function 401 / non-2xx 问题，并显式携带当前登录令牌。
- 修复俄文月份表缺少“июля”造成 10 月错误显示成 11 月的问题。
- 修复文件页面顶部“Обновить / 更新”导致 iframe 重新加载后上半部分被裁切的问题；按钮现在只安全刷新当前显示并回到顶部。
- 上传旧 TXT/HTML 模板时会自动修复旧版缺少 7 月和危险刷新逻辑，避免旧模板再次把 bug 带回系统。
- 保留 V19 的模板/文件/账户/回执关系、回执分用户文件夹、批量删除、文件重命名等功能。
