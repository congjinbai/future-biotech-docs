# FUTURE HEALTH 文档系统 V8

本版更新：

- 注册审核提示跟随系统语言显示。
- 俄文审核提示优化为：`Ваша заявка на регистрацию находится на проверке. Дождитесь подтверждения администратора или позвоните администратору, чтобы ускорить проверку.`

- 登录页“个人编号 / Личный ID”旁增加“请输入手机号 / Введите номер телефона”。

- 管理员通知数字每 15 秒轻量刷新一次。
- 管理员和使用者的文件查看/填写页面删除了遮挡内容的左上角返回按钮，只保留页面底部可靠的返回按钮。

## V9 免费提示音
- 手机/电脑网页打开并登录后，第一次触摸/点击页面会激活浏览器音频。
- 管理员收到新的注册申请或文件请求时，会播放短提示音。
- 普通用户在管理员新增文件后，页面检测到新文件时会播放短提示音。
- 若浏览器允许通知权限，也会尝试显示系统通知。
- 这是免费网页通知，不是运营商短信；网页完全关闭或被手机系统挂起时不能保证响铃。
