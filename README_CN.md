# FUTURE HEALTH V23

本版本为 V22 的界面与文件填写流程微调版。

主要调整：
- 模板页“新增模板 / 删除模板”按钮互换位置。
- 模板、文件、账户批量删除工具栏统一为“取消 / 全选 / 删除所选”。
- 移除日期日历按钮，恢复纯数字日期输入。
- 日期进度按钮移到“下一步 / 完成”按钮上方。
- 完成最后一个日期后，两个进度按钮均显示绿色；移除“填写完成”提示条。
- 手写板“确认 / 清除”按钮互换位置。
- “生成图片”未启用状态改为浅灰色。
- 图片预览页提交按钮固定按当前文件语言显示：中文“提交”，俄文“Отправить”，不再变成“分享 / Поделиться”。
- 文件顶部语言切换按钮与“更新”按钮互换位置。
