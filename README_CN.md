# FUTURE HEALTH V14

本版在注册审核等待界面增加了网页内“更新 / Обновить”按钮，主要用于把网页添加到手机桌面（PWA/独立网页模式）后没有浏览器刷新按钮的情况。

- 注册提交后，等待界面显示手动更新按钮。
- 中文提示：请手动更新界面。管理员通过验证后，更新即可自动进入系统。
- 俄文提示：Обновите страницу вручную. После подтверждения администратором обновление автоматически откроет систему.
- 管理员尚未通过时，更新后仍保持等待状态。
- 管理员已通过时，更新后由系统正常进入已批准账户。
- 原有自动每 4 秒检查仍保留，手动更新作为可靠备用方式。
