# FUTURE HEALTH V15

本版新增：

1. 注册等待界面继续自动检查审核状态；注册按钮会提前激活网页提示音和系统通知权限。管理员通过后，只要等待页仍保持打开，系统会在等待页提示、播放铃音并自动进入系统；手动“更新”仍保留作备用。
2. 管理员新增“回执/Расписки”文件夹。用户签字并生成图片后，原“分享”按钮改为“提交回执/Отправить расписку”，签字图片会直接上传到私有 Supabase Storage 并记录到管理员回执箱。
3. 回执标签右上角显示未读红色数字。管理员可查看、下载，并在支持 Web Share 的手机上通过微信等应用转发。

数据库和私有存储桶已同步建立，无需手动执行 SQL。
