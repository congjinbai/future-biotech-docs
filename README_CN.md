# FUTURE HEALTH V18

本版更新：
- 新用户仅填写一种语言姓名后，管理员批准时自动补齐另一语言：俄文姓名自动生成中文音译；中文姓名自动生成大写拼音姓名。
- 俄文/拉丁姓名统一大写。
- 回执标签中俄文切换修复。
- 回执按用户建立独立文件夹，文件按生成时间排列；支持查看、下载、单个删除、全选/批量删除。
- 管理员账户页增加“删除账户”，支持单选、多选批量删除。
- 文件管理中的所有文件增加“重命名”。

注意：自动姓名音译用于初始生成，管理员仍可在账户管理中人工校正。

- V19：管理员可对待审核注册发送修改提示；用户在审核页直接修改姓名/手机号并重新提交。
- V19：账户批量删除模式增加“全选”按钮。
