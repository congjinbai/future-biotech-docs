# FUTURE BIOTECH 文件系统 V3

V3 的核心变化：

1. 填写和签字时只显示当前选择的语言。
2. 俄文签字和中文签字完全独立，绝不自动复制。
3. 确认签字后显示最终俄中左右双栏版式。
4. 打印 / PDF / PNG 均使用左右双栏最终版式。
5. 日期、期间、姓名等填写字段在两种语言版本之间同步。
6. 保留原有四类模板：两家公司工资收条、单家公司工资收条、法律咨询费收条、申请书。

## 更新 GitHub
将 `index.html`、`styles.css`、`app.js` 覆盖到现有 `future-biotech-docs` 仓库根目录。`config.js` 可以继续使用本包中的已配置版本。
